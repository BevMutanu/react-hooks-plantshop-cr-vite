# Plantsy Plant Shop

A React application for managing plants in a plant shop inventory system.

## Features

- View all plants on page load
- Add new plants using a form
- Mark plants as sold out
- Search plants by name
- Persistent backend using JSON Server

---

## Technologies Used

- React
- Vite
- JSON Server
- Vitest
- React Testing Library
